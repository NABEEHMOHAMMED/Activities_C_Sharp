# 🛍️ يمن مارت

> **تطبيق التجارة الإلكترونية اليمني المتكامل**  
> منصة موثوقة تربط التجار والمستهلكين في سوق واحد آمن وحديث

---

## 📋 نظرة عامة

**يمن مارت** هو تطبيق تجارة إلكترونية متطور مصمم خصيصاً لتلبية احتياجات السوق اليمني. يوفر التطبيق تجربة تسوق متكاملة وسلسة للمستخدمين مع واجهة عربية كاملة ودعم RTL، بالإضافة إلى أدوات متقدمة للتجار لإدارة منتجاتهم وطلبات العملاء.

تم بناء يمن مارت باستخدام أحدث التقنيات والمعايير الدولية، مع التركيز على الأداء العالي والأمان والقابلية للتوسع.

---

## 🎯 الأهداف الرئيسية

| الهدف | الوصف |
|:---:|---:|
| **ربط السوق** | إنشاء منصة موحدة تجمع التجار والمستهلكين في مكان واحد آمن وموثوق |
| **تجربة عربية** | توفير تجربة تسوق متكاملة باللغة العربية مع دعم كامل لـ RTL |
| **الحداثة التقنية** | استخدام أحدث التقنيات لضمان الأداء والأمان والاستقرار |

## ✨ الميزات الرئيسية

### 🔐 نظام المصادقة المتقدم

يوفر التطبيق عدة طرق آمنة للتسجيل والدخول:

- تسجيل الدخول وإنشاء حساب جديد بسهولة
- التحقق الثنائي عبر رموز OTP المرسلة للهاتف
- استعادة آمنة لكلمات المرور المنسية
- تسجيل الدخول السريع عبر حساب Google

### 🏪 إدارة المتاجر والمنتجات

تصفح سهل وسريع لآلاف المنتجات:

- استعراض شامل للمتاجر المتاحة على المنصة
- عرض تفصيلي لمعلومات كل متجر ومنتجاته
- تصفح منظم للفئات المختلفة للمنتجات
- قوائم تفصيلية بجميع المنتجات مع الصور والأسعار
- معلومات شاملة عن كل منتج مع تقييمات المستخدمين

### 🛒 تجربة التسوق السلسة

من البحث إلى الشراء، كل خطوة مصممة بعناية:

- بحث ذكي مع خيارات تصفية وترتيب متقدمة
- إضافة سريعة للمنتجات إلى السلة
- إدارة كاملة للسلة (إضافة، حذف، تعديل الكميات)
- مراجعة شاملة للطلب قبل الدفع

### 💳 نظام الدفع والطلبات

عملية دفع آمنة وموثوقة:

- عملية شراء متكاملة وآمنة
- اختيار عنوان التسليم وطريقة الدفع
- تأكيد فوري للطلب مع رقم تتبع
- سجل شامل لجميع الطلبات السابقة
- تتبع فوري لحالة الشحن والتوصيل

### 👤 الملف الشخصي والإعدادات

إدارة شاملة لحسابك الشخصي:

- تعديل البيانات الشخصية والملف الشخصي
- إدارة عناوين التسليم المتعددة
- إعدادات التطبيق والتفضيلات
- قائمة المنتجات المفضلة للوصول السريع
- إشعارات فورية للطلبات والعروض الخاصة

## 🏗️ الهندسة المعمارية

يتبع التطبيق نمط **Clean Architecture** الحديث، الذي يضمن فصل الاهتمامات وسهولة الصيانة والاختبار:

```
┌───────────────────────────────────────────────┐
│ طبقة العرض (Presentation Layer)               │
│ • الشاشات والـ Widgets                        │
│ • إدارة الحالة (Riverpod Providers)           │
│ • تفاعل المستخدم                              │
└───────────────────────────────────────────────┘
                 ↓
┌───────────────────────────────────────────────┐
│ طبقة المجال (Domain Layer)                    │
│ • المنطق التجاري الأساسي                      │
│ • Use Cases والحالات الاستخدام                │
│ • عقود المستودعات (Repository Contracts)      │
└───────────────────────────────────────────────┘
                 ↓
┌───────────────────────────────────────────────┐
│ طبقة البيانات (Data Layer)                    │
│ • مصادر البيانات (Remote & Local)             │
│ • نماذج البيانات (Models)                     │
│ • تطبيق المستودعات (Repository Implementation)│
└───────────────────────────────────────────────┘
```

هذا النمط يوفر:

- **سهولة الاختبار**: كل طبقة يمكن اختبارها بشكل مستقل
- **المرونة**: يمكن تغيير مصادر البيانات دون التأثير على المنطق التجاري
- **الصيانة**: كود منظم وسهل الفهم والتطوير

## 🎨 تصميم واجهة المستخدم

تم تصميم واجهة يمن مارت بعناية لضمان تجربة مستخدم ممتازة:

### المعايير التصميمية

- **Material Design 3**: اتباع أحدث معايير التصميم من Google
- **دعم RTL كامل**: واجهة مثالية للغة العربية واتجاه الكتابة من اليمين إلى اليسار
- **خط Cairo**: خط عربي احترافي يوفر قراءة مريحة وواضحة

### العناصر التفاعلية

- **بانرات ترويجية متحركة**: عروض جذابة تتحرك بسلاسة
- **بطاقات منتجات أنيقة**: عرض احترافي لكل منتج
- **تأثيرات تحميل احترافية**: رسوم متحركة Shimmer أثناء تحميل البيانات
- **محملات هيكلية**: عرض تدريجي للمحتوى أثناء التحميل
- **رسوم متحركة Lottie**: تأثيرات بصرية تفاعلية وسلسة

### الخيارات المرنة

- **الوضع المظلم والفاتح**: دعم كامل للمظهرين المختلفين
- **تصميم متجاوب**: واجهة مناسبة لجميع أحجام الشاشات
- **صور محسّنة**: تحميل سريع وتخزين مؤقت ذكي للصور

## 📱 هيكل التنقل

```
┌───────────────────────────────┐

└───────────────────────────────┘
                 ↓
┌───────────────────────────────┐

                 ↓

                 ↓

```

- **تفاصيل المنتج**
